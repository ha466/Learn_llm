Understanding the Architecture

Embeddings

Words are converted into fixed-size vectors. In a real GPT model, these vectors have 12,288 dimensions! Here, we visualize them as 6 simple blocks.

Attention (Q, K, V)

Imagine a filing system.
Query (Q): What am I looking for?
Key (K): What content does this file have?
Value (V): The actual content of the file.
The model multiplies Q and K to find the best match, then extracts V.

Feed Forward (MLP)

This is where the model "thinks". It's a standard neural network layer that processes the information gathered by attention. It has 4x as many neurons as the embedding size.
